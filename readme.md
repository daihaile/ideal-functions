# IdealFunctions

## How to run the program

1. Make sure the input files exist:
   - `data/train.csv`
   - `data/ideal.csv`
   - `data/test.csv`

2. Run the main script from the project root:
   ```bash
   python main.py
   ```

### Output
After running, you should get:
- mapped test results CSV at: `output/test_results.csv`
- an interactive visualization report at: `visuals.html`
